The API reference at [/api/](/api/) reflects the same XML documentation comments that ship with the `Fluence.Wpf` NuGet package.

If you arrived here from an external link and see this page instead of the API tree, the API section has not been published yet for the current build. The most recent published version always lives at:

- [https://sintaxasn.github.io/Fluence.Wpf/api/](https://sintaxasn.github.io/Fluence.Wpf/api/)

## What's in the reference

- All public types in the `Fluence.Wpf`, `Fluence.Wpf.Controls`, `Fluence.Wpf.Enums`, and `Fluence.Wpf.Helpers` namespaces.
- Dependency properties, attached properties, routed events, and template parts.
- Automation peers and the public enumerations used to configure controls.

For usage guidance, start with [Documentation](/docs/). Use the API reference when you need exact member names, signatures, and namespace locations.
