# Support

Use these paths for help:

- **Bug reports**: open a GitHub issue with a minimal reproduction, target framework, Windows version, and screenshots when the issue is visual.
- **Feature requests**: open a GitHub issue describing the WinUI control or feature you're requesting, with WinUI or in-tree references when possible.
- **Security reports**: follow [SECURITY.md](SECURITY.md).

Before filing, check [KNOWN_ISSUES.md](KNOWN_ISSUES.md) and the current [CHANGELOG.md](CHANGELOG.md).
