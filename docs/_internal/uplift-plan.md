# WI-3 uplift plan — Fluence.Wpf control templates

> Internal working document. Not part of the public `docs/` set per CLAUDE.md §10.
> Research output only; no source modifications accompany this file.

## Scope

**In scope.** The 28 control template `ResourceDictionary` files under
[Fluence.Wpf/Themes/Controls/](../../Fluence.Wpf/Themes/Controls/), minus
`FluenceWindow.xaml` (already audited in
[wi2-audit-findings.md](wi2-audit-findings.md)).

**Comparison authority.** WinUI 3 CommonStyles at
`F:/StagedMigration/WinUI_XAML/Controls/*.xaml` and `*_themeresources.xaml`,
per CLAUDE.md §4.2 (visual tokens, individual controls). .NET 10 WPF
`Themes/` acts as a tie-breaker only where a WPF-native idiom is required.

**Ranking.** Severity tiers are `both` (visual + behavioural) → `behavioural`
only → `visual` only. Within each tier: S → M → L. The known-failing test
`RadioButton_OuterRing_UsesControlStrongStrokeBrush` anchors the first
visual-tier row and is retained even though the XAML currently already
references `ControlStrongStrokeColorDefaultBrush` (the failure stems from
suite-level theme leakage documented in CLAUDE.md §9 — the uplift is the
test-setup contract, not the brush key itself).
