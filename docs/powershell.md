# Fluence.Wpf from PowerShell

The `Fluence.Wpf.PowerShell` module is the primary interface for scripts. Its documentation lives under [docs/powershell/](powershell/README.md): a [tutorial](powershell/tutorial.md), how-to guides, one [reference](powershell/reference/README.md) page per cmdlet, and an [explanation](powershell/explanation.md) of its design. Start with the tutorial, then try the [module examples](../Fluence.Wpf.PowerShell.Module/examples/).
