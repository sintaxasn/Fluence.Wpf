# Fluence.Wpf MVVM Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** Historical implementation plan. The MVVM demo is implemented; prefer the current source files and `CLAUDE.md §8` over unchecked task snippets below.

**Goal:** Add `Fluence.Wpf.Demo.Mvvm` — a minimal but well-structured WPF Task Manager app that demonstrates CommunityToolkit.Mvvm patterns using Fluence.Wpf controls.

**Architecture:** Single project added to the existing `Fluence.Wpf.sln`. A `MainViewModel` owns an `ObservableCollection<TaskItemViewModel>` and exposes source-generated `RelayCommand`s for add/delete/clear. The `MainWindow` has zero logic in code-behind — only `InitializeComponent()`. An `EnumToBoolConverter` drives `RadioButton` filter selection. No `CollectionViewSource`; filtering rebuilds a `DisplayedTasks` collection to keep data flow explicit.

**Tech Stack:** WPF, `net10.0-windows10.0.26100.0`, C# 12 (latest), CommunityToolkit.Mvvm 8.4.0, Fluence.Wpf (project reference), BSD 3-Clause header on every `.cs` file.

## MVVM concepts demonstrated

| Concept | Where |
|---------|-------|
| `ObservableObject` base class | `TaskItemViewModel`, `MainViewModel` |
| `[ObservableProperty]` source-generated property | `_title`, `_isCompleted`, `_newTaskText`, `_displayedTasks`, `_activeFilter` |
| Explicit derived-property notifications | `MainViewModel` rebuilds `DisplayedTasks`, then raises `StatusText` / `ProgressValue` notifications (no `[NotifyPropertyChangedFor]` on `_activeFilter`) |
| `[RelayCommand(CanExecute = …)]` | `Add` + `CanAdd` pair |
| `partial void OnXxxChanged` callback | `OnNewTaskTextChanged` → `AddCommand.NotifyCanExecuteChanged()` |
| `ObservableCollection<T>` | `_allTasks` (source), `DisplayedTasks` (view) |
| `CommandParameter` in `DataTemplate` | Delete button passes the item itself |
| `RelativeSource AncestorType` binding | Delete command inside the task-item `DataTemplate` |
| `EnumToBoolConverter` | `RadioButton.IsChecked` ↔ `FilterMode` enum |
| `DataTrigger` strikethrough | `IsCompleted=True` → `TextDecorations.Strikethrough` |
| Zero code-behind | `MainWindow.xaml.cs` only calls `InitializeComponent()` |

```csharp
/*
 * Copyright 2026 Dan Cunningham  [... full BSD header ...]
 */
using System.Collections.Generic;
using System.Collections.ObjectModel;
using System.ComponentModel;
using System.Linq;
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;

namespace Fluence.Wpf.Demo.Mvvm.ViewModels
{
    /// <summary>
    /// Root ViewModel for the Task Manager window. Demonstrates:
    /// <list type="bullet">
    ///   <item><description><c>[ObservableProperty]</c> — backing fields with auto-notification</description></item>
    ///   <item><description><c>[RelayCommand(CanExecute)]</c> — enabled/disabled command binding</description></item>
    ///   <item><description><c>partial void OnXxxChanged</c> — source-generated change callbacks</description></item>
    ///   <item><description><c>ObservableCollection</c> — live-updating list</description></item>
    ///   <item><description>Derived properties via <c>OnPropertyChanged</c></description></item>
    /// </list>
    /// </summary>
    public partial class MainViewModel : ObservableObject
    {
        // The full unfiltered source list — never bound to directly.
        private readonly ObservableCollection<TaskItemViewModel> _allTasks = new();

        // ---------------------------------------------------------------
        // Observable properties (source-generated by CommunityToolkit.Mvvm)
        // ---------------------------------------------------------------

        /// <summary>
        /// The filtered view of tasks that the ListView binds to.
        /// Rebuilt by <see cref="Refresh"/> whenever tasks or filter change.
        /// </summary>
        [ObservableProperty]
        private ObservableCollection<TaskItemViewModel> _displayedTasks = new();

        /// <summary>
        /// Text the user types for a new task. Two-way bound to the TextBox.
        /// The <c>OnNewTaskTextChanged</c> callback re-evaluates <see cref="AddCommand"/>.
        /// </summary>
        [ObservableProperty]
        private string _newTaskText = string.Empty;

        /// <summary>
        /// Current filter selection. Changing it triggers <c>OnActiveFilterChanged</c>
        /// which calls <see cref="Refresh"/>, and <c>[NotifyPropertyChangedFor]</c>
        /// raises change events for the two derived properties below.
        /// </summary>
        [ObservableProperty]
        [NotifyPropertyChangedFor(nameof(StatusText))]
        [NotifyPropertyChangedFor(nameof(ProgressValue))]
        private FilterMode _activeFilter = FilterMode.All;

        // ---------------------------------------------------------------
        // Derived / computed properties
        // ---------------------------------------------------------------

        /// <summary>
        /// Human-readable task completion summary shown in the footer.
        /// </summary>
        public string StatusText
        {
            get
            {
                int total = _allTasks.Count;
                int done  = _allTasks.Count(t => t.IsCompleted);
                return total == 0 ? "No tasks" : $"{done} of {total} completed";
            }
        }

        /// <summary>
        /// Progress bar value 0-100 based on completion ratio.
        /// </summary>
        public double ProgressValue =>
            _allTasks.Count == 0
                ? 0
                : (double)_allTasks.Count(t => t.IsCompleted) / _allTasks.Count * 100;

        // ---------------------------------------------------------------
        // Commands
        // ---------------------------------------------------------------

        /// <summary>
        /// Adds a new task from <see cref="NewTaskText"/>.
        /// Disabled (grayed out) when the text box is blank — CanExecute is
        /// re-evaluated every time <see cref="NewTaskText"/> changes via
        /// <see cref="OnNewTaskTextChanged"/>.
        /// </summary>
        [RelayCommand(CanExecute = nameof(CanAdd))]
        private void Add()
        {
            var item = new TaskItemViewModel(NewTaskText.Trim());
            // Subscribe so completion toggles trigger a filter refresh.
            item.PropertyChanged += OnItemPropertyChanged;
            _allTasks.Add(item);
            NewTaskText = string.Empty;
            Refresh();
        }

        private bool CanAdd() => !string.IsNullOrWhiteSpace(NewTaskText);

        // Source-generated partial callback — fires after NewTaskText setter runs.
        partial void OnNewTaskTextChanged(string value) =>
            AddCommand.NotifyCanExecuteChanged();

        /// <summary>
        /// Removes a specific task. Bound in the DataTemplate via
        /// <c>RelativeSource AncestorType=Window</c> with <c>CommandParameter="{Binding}"</c>.
        /// </summary>
        [RelayCommand]
        private void Delete(TaskItemViewModel item)
        {
            item.PropertyChanged -= OnItemPropertyChanged;
            _allTasks.Remove(item);
            Refresh();
        }

        /// <summary>
        /// Removes all completed tasks at once.
        /// </summary>
        [RelayCommand]
        private void ClearCompleted()
        {
            foreach (TaskItemViewModel t in _allTasks.Where(t => t.IsCompleted).ToList())
            {
                t.PropertyChanged -= OnItemPropertyChanged;
                _allTasks.Remove(t);
            }
            Refresh();
        }

        // ---------------------------------------------------------------
        // Internal helpers
        // ---------------------------------------------------------------

        // Source-generated partial callback — fires when ActiveFilter changes.
        partial void OnActiveFilterChanged(FilterMode value) => Refresh();

        // Propagate IsCompleted change on any item → rebuild filter + derived props.
        private void OnItemPropertyChanged(object sender, PropertyChangedEventArgs e)
        {
            if (e.PropertyName == nameof(TaskItemViewModel.IsCompleted))
                Refresh();
        }

        // Rebuild DisplayedTasks from _allTasks + ActiveFilter, then notify
        // the two derived properties.
        private void Refresh()
        {
            IEnumerable<TaskItemViewModel> view = ActiveFilter switch
            {
                FilterMode.Pending   => _allTasks.Where(t => !t.IsCompleted),
                FilterMode.Completed => _allTasks.Where(t =>  t.IsCompleted),
                _                    => (IEnumerable<TaskItemViewModel>)_allTasks,
            };
            DisplayedTasks = new ObservableCollection<TaskItemViewModel>(view);
            OnPropertyChanged(nameof(StatusText));
            OnPropertyChanged(nameof(ProgressValue));
        }
    }
}
```

```csharp
using System;
using System.Globalization;
using System.Windows.Data;

namespace Fluence.Wpf.Demo.Mvvm.Converters
{
    /// <summary>
    /// Returns <see langword="true"/> when the bound enum value equals
    /// <see cref="IValueConverter.Convert"/>'s <paramref name="parameter"/>.
    /// ConvertBack sets the enum to <paramref name="parameter"/> when the
    /// RadioButton becomes checked.
    /// </summary>
    public class EnumToBoolConverter : IValueConverter
    {
        /// <inheritdoc />
        public object Convert(object value, Type targetType, object parameter, CultureInfo culture) =>
            value is not null && value.Equals(parameter);

        /// <inheritdoc />
        public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture) =>
            value is true ? parameter : Binding.DoNothing;
    }
}
```
